# 05 — Ai Shot List Generator

## Objective
Build an industry-oriented AI video generation workflow for this use case.

## Workflow
1. Define the audience and video objective.
2. Generate or prepare the script, prompts and visual assets.
3. Generate video clips with a compatible AI video provider.
4. Add voice, music, captions and branding where required.
5. Assemble, review and export the final video.

## Suggested Stack
- Python
- LLM for scripts/prompts
- Compatible text/image-to-video provider
- FFmpeg for post-processing
- Optional TTS and subtitle services

## Teaching Outcomes
- Prompt engineering
- AI video workflow design
- Asset and shot planning
- Post-production automation
- Responsible commercial content creation
